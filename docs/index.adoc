= AsciiDoc comments

:product-short: Container tools

This package allows you to add unique IDs to each AsciiDoc block.

. Navigate to xref:test.adoc[Test document] or xref:master.adoc[Master document demo].

. Highlight some text in an addressable block and click the floating copy link icon.

The generated copy link UI copies a Markdown link to the nearest block ID. If text is selected, it appends the selected text as a Markdown quote. If no text is selected, it copies only the Markdown link.

Use the floating icon to Copy Markdown link for the selected block.

Each block is uniquely addressable as a URL, for example xref:test.adoc#install--block-1[a block lower in the document].

To use this package to convert your AsciiDoc to HTML, install it using

[source,bash]
----
npm i -g @techwriter/asciidoc-comments
----

To convert your AsciiDoc files:

[source,bash]
----
asciidoc-comments <filename>
----

== Attribute Button Options

By default, attribute references like `{product-short}` render as interactive buttons showing the current value. You can configure alternative values that readers can select by clicking the button.

Create an options file (e.g., `options.json`) with this structure:

[source,json]
----
{
  "version": 1,
  "fields": {
    "product-short": {
      "default": "Developer Hub",
      "options": ["podman", "docker", "kubernetes"]
    }
  }
}
----

Then render with the options file:

[source,bash]
----
asciidoc-comments --attribute-add options.json <filename>
----

You can also use AsciiDoc format for alternatives:

[source,asciidoc]
----
:product-short: Developer Hub
:product-short: podman
:product-short: docker
----

When readers click an attribute button, they see a list of configured options. Selecting a value updates all instances of that attribute throughout the page.
All values for {product-short} are affected.

== Deprecated Bookmarklet

The deprecated copy-link bookmarklet remains available for compatibility, but the generated copy link UI is the preferred workflow. The bookmarklet may be removed in a future release.
