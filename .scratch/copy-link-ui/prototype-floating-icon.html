PROTOTYPE - Copy Link UI

Select text in the rendered content. The prototype shows three candidate placements and the copied Markdown state.

Install

Install the package globally when you want to convert AsciiDoc files from the command line. Select this sentence and press the floating copy button.

  • Generated IDs make each block addressable.

  • Author-provided IDs should work the same way.

Start include: module.adoc

Usage

Attribute buttons such as should still receive clicks without opening the copy link workflow.
